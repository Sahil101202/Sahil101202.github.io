Privacy Policy

Effective November 16, 2026 · MYSTRAVYN Automation

MYSTRAVYN Automation is an owner-authorized application for a YouTube channel, currently intended for use by the channel owner. It is not a public sign-in service. It uses YouTube API Services and Google OAuth to perform the functions described here.

1. Operator and contact

The MYSTRAVYN Automation application supports the MYSTRAVYN YouTube channel. For privacy questions, access requests, or deletion requests, contact theelisora@gmail.com.

2. Google and YouTube information accessed

When the channel owner authorizes access through Google's consent screen, the application can access the following information, depending on the permissions granted:

  • Channel identity data, including channel identifier, title and associated public metadata, to verify the selected YouTube channel.
  • Channel and video performance information through the YouTube Analytics API, including views, watch time, average view duration and subscriber metrics, for the owner's content-performance review.
  • Existing uploads' identifiers, titles and descriptions, to prevent duplicate video publishing.
  • Authorization tokens necessary to make permitted YouTube API requests, including upload actions where the owner has granted the required scope.
  • The owner-provided video files and metadata necessary for uploads to the owner's YouTube channel.

The current implementation requests the youtube.readonly, yt-analytics.readonly and youtube.upload OAuth scopes through separate authorizations as required.

3. Purpose and use

Authorized data is used only to verify the connected channel, render and upload authorized videos, avoid duplicate publishing, and evaluate the performance of MYSTRAVYN videos. Data is not used for advertising targeting, profiling unrelated individuals, or sale to data brokers.

4. Storage and service providers

Google OAuth authorization data is supplied securely to private GitHub Actions workflows using GitHub repository secrets. Source code, production metadata and scheduled jobs are managed through GitHub. Performance summaries may be stored temporarily as private workflow artifacts, with workflow-specific retention periods (currently configured for seven days for analytics artifacts). Public videos and their metadata are stored and processed by YouTube when uploaded.

Google/YouTube and GitHub process information to provide their services; access to authorized channel data should be limited to the channel owner and approved operational agents. The public website itself does not intentionally set first-party analytics or marketing cookies. GitHub Pages may collect technical request information under GitHub's privacy statement.

5. Retention, deletion, and revocation

Authorization data is retained only while needed for the owner's authorized automation and can be deleted by removing the corresponding GitHub Actions secrets and local token files. When access is revoked or deletion is requested, authorized user data under the application's control should be deleted promptly and within applicable YouTube API policy deadlines. You can request deletion by contacting theelisora@gmail.com.

The channel owner may independently revoke access at any time from Google Account → Third-party apps and services. Revoking access will prevent further authorized YouTube requests but does not delete videos already published on YouTube; existing videos can be managed in YouTube Studio.

6. Permissions and account security

Access permissions are requested through the official Google OAuth consent flow, not by collecting Google passwords. Do not place OAuth client secrets or refresh tokens in the public website or a public GitHub repository. The authorizing user remains in control of grant/revocation, upload visibility, and video-management decisions.

7. Data sharing and independent policies

Channel data is not sold or shared for third-party advertising. Necessary service processing occurs through Google/YouTube and GitHub, and through providers explicitly approved for channel operations if used. The application's use of information received from Google APIs is subject to the Google API Services User Data Policy. The Google Privacy Policy and YouTube Terms of Service also apply.

8. Changes

This policy may be updated when application functionality or data handling changes. Any material change to the collection or use of authorized Google data must be communicated and, where required, renewed consent obtained before the expanded use.

9. Contact

Privacy inquiries or deletion requests: theelisora@gmail.com.
